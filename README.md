📊 Social Media Behavioral Analytics Dashboard

An interactive Tableau dashboard project designed to analyze user behavior across multiple social media platforms and transform raw engagement data into meaningful business insights.

🚀 Project Overview

Social media platforms generate massive amounts of behavioral data every day.
This project explores how users interact with platforms like Instagram, Twitter, Facebook, LinkedIn, Snapchat, Pinterest, and TikTok using interactive Tableau visualizations.

The dashboard focuses on:

User engagement behavior
Daily screen time analysis
Posting activity trends
Platform popularity comparison
Content creation patterns
User attention vs interaction analysis

The goal of this project is not just visualization — but storytelling through data.

🎯 Objectives
Analyze user behavior across different social media platforms
Identify the most addictive platforms based on usage time
Compare engagement metrics between platforms
Understand the relationship between posting activity and screen time
Create a clean, interactive, and portfolio-ready Tableau dashboard
